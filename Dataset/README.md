# Dataset

This project uses the **DataCo SMART Supply Chain Dataset** for shipping and delivery performance analysis.

### Dataset Files

| Dataset | Description | Link |
|---|---|---|
| Original Dataset | Raw DataCo supply chain dataset | [Download from Kaggle](https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis) |
| Cleaned Dataset | Cleaned dataset prepared using Excel Power Query | [Download Cleaned Dataset](https://docs.google.com/spreadsheets/d/1BOck6H1RG6J1hG5ME2i8Qb3zPAouSTzj/edit?usp=drive_link&ouid=115016054409817137215&rtpof=true&sd=true) |
| Data Dictionary | Dataset column descriptions | [View File](https://drive.google.com/file/d/1mZh3lKsVI6zBSSytYQoIb6v7lMVspp-h/view?usp=drive_link) |

**Note:** The cleaned dataset is hosted externally because of its large file size.
